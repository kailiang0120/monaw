## Review fixes retest (uncommitted working tree)

The following results apply to the local changes on top of `38e3e34`. They
describe an uncommitted working tree, not a release commit.

  tests and 40 Electron unit tests passed; TypeScript and renderer build passed.

  forced backend exit, the original Run continued on attempt 2 with one user

- `npm run test:app`: all 14 Electron/source-backend workflows passed, including
  default-policy Undo confirmation and an external-edit conflict.
- The rebuilt unsigned installer is `frontend/release/Monaw-Setup-1.1.0-x64.exe`
  (141480212 bytes), SHA-256
  `6214A59024017E462A4CE39B4D6C2CB1F0FDB42AA7CAD3543A32821079652369`.
  `npm run test:packaged` passed 6 checks; the live account check was skipped.

  and the published v1.0.0 installer. Both hashes and the installed version were
  checked; the historical message, workspace, settings and disabled task survived.

  terminal Run event retention and unshared snapshot reclamation are implemented.
  See [operations.md](operations.md) and [permissions.md](permissions.md).
